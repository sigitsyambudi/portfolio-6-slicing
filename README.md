# Portfolio 6

A responsive single-page portfolio implemented from the supplied Figma design with Next.js, TypeScript, Tailwind CSS, CSS Modules, and Motion.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Validation

```bash
npx tsc --noEmit
npm run lint
npm run build
```

To run the production build locally:

```bash
npm run start
```

## Contact form

The contact form is intentionally a design-demo experience. It validates input and exposes success/failure dialog previews, but it does not send or store messages.
